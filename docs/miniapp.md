# MAKSIM: оформление и мини-приложение

Публичная витрина доступна по `/miniapp`. Оформление адаптировано по предоставленным скриншотам Sky Jewelry: тёплая тёмная палитра, крупный визуальный блок, светлая основная карточка, парные карточки и закреплённое нижнее меню. Бренд и содержание — MAKSIM. Используются сгенерированные по предоставленному пользователем референсу портреты Максима в единой тёплой палитре; фотографии и логотипы Sky Jewelry не используются.

## Что увидит пользователь

На `/start` — баннер и приветственный текст с кнопкой «✨ Войти в приложение». При корректном HTTPS `APP_URL` бот также задаёт пользователю кнопку «Открыть» рядом с полем сообщения. В повторном меню кнопка приложения сохраняется, существующие кнопки разделов остаются доступны. Настройка `welcome` продолжает управлять приветственным текстом; длинный текст отправляется отдельно, чтобы не превышать лимит подписи Telegram. Сценарий `login_…` для входа администратора обрабатывается отдельно.

Разделы приложения: главная, практики, встречи, сообщество, о Максиме. Публичные опубликованные материалы загружаются из существующей БД и редактируются в админке. На локальных скриншотах использованы тестовые материалы; в рабочую БД они не добавляются. Пустой каталог показывает сообщение о будущих материалах, ошибка загрузки — предложение обновить страницу или открыть бота.

Аудио, оформление заказов, запись, консультация и личный доступ остаются в существующем боте: ссылки `start=open_…` открывают нужный раздел. Витрина не является личным кабинетом и не доверяет данным Telegram SDK для авторизации. Платные файлы, пользовательские записи и заказы в публичные данные страницы не включаются. Telegram SDK используется для внешнего вида окна, кнопки «Назад» и открытия бота. В обычном браузере витрина тоже доступна.

## Публикация и проверка

1. Дождитесь `Ready` нового production deployment в Vercel.
2. Откройте `https://maksim-seven.vercel.app/miniapp` и проверьте главную и вкладки.
3. Отправьте боту `/start`, дождитесь обработки планировщиком. Нажмите «✨ Войти в приложение».
4. Если кнопка приложения не видна, отправьте `/app`: бот пришлёт отдельную кнопку открытия приложения. Команда `/menu` возвращает полное меню.
5. Проверьте кнопку бесплатной практики: она должна открывать нужный сценарий бота. Если аудио ещё не опубликовано, бот сообщит об этом и покажет меню с кнопкой приложения.
6. При желании задайте в BotFather → `/mybots` → свой бот → Bot Settings → Menu Button адрес `https://maksim-seven.vercel.app/miniapp` и название «Открыть». Это делает кнопку доступной до нового `/start`; сам бот задаёт её для пользователя при приветствии.

Новые секреты и миграции не нужны. `APP_URL` должен содержать основной HTTPS-адрес приложения. Telegram WebApp не добавляется в клавиатуру при отсутствии корректного HTTPS-адреса. Не перенастраивайте webhook на адрес `/miniapp` — его маршрут остаётся прежним.

Страница `/miniapp` разрешена во фреймах официального Telegram Web; остальные страницы сохраняют запрет встраивания через CSP `frame-ancestors 'none'`. Сборка проверяет включение Prisma WASM и PNG-баннера в serverless-функции.

## Проверено локально

69 Vitest-тестов (включая кнопки приложения, переходы из витрины, `/app`, возврат меню при отсутствии бесплатной практики, сохранение ограничения платного доступа и входа администратора), 13 тестов webhook/диагностики, production-сборка. Chromium: пять вкладок, каталог и фильтрация, закрытие описания по Escape, пустой каталог, ссылки в Telegram, настройка SDK, HTTP-заголовки и ширины 320/390/1280. SDK и исходящие Telegram-вызовы в тестах моделировались; реальное открытие в Telegram проверяется после публикации.

## Фотографии

Вместо пейзажного баннера главный экран и приветствие бота используют согласованный приглашающий портрет. Три первоначальных портрета размещены в карточках практик и встреч, в разделе «О Максиме» и как обложки материалов без собственного изображения. Обложки из админки сохраняют приоритет. Фотографии сгенерированы по предоставленному пользователем референсу. Исходники сохранены без изменения; отдельные кадры триптиха выбираются вёрсткой. Next Image автоматически подаёт адаптивные сжатые изображения, главный портрет загружается с приоритетом.

Добавление фотографий проверено production-сборкой и в Chromium: загрузка всех кадров через Next Image, главная, «О Максиме», обложки практик и встреч, PNG для бота и ширины 320/390/1280. Оптимизированные WebP в проверке занимали примерно 90–140 КБ на вариант.
