# Руководство Максима

## Первый вход

Войдите по адресу `/admin` через Telegram. Telegram ID должен присутствовать в OWNER_TELEGRAM_IDS. В разделе «Команда» владелец может добавить администратора; роль ADMIN работает с контентом, платежами, рассылками и заявками. Только владелец управляет настройками, командой, отзывом доступа, участниками, экспортом и возвратами.

## Контент

1. Отправьте боту аудио с вашего административного Telegram-аккаунта. Бот вернёт Telegram file_id.
2. «Медитации → Добавить»: название, описание, категория, продолжительность, file_id; при необходимости HTTPS-обложка. Отметьте «Бесплатная практика» для первого аудио. Если бесплатных несколько, приветственный сценарий выдаёт первую доступную — рекомендуется публиковать одну вводную.
3. Для платной практики создайте продукт MEDITATION, задайте цену **в копейках** (150000 = 1500 ₽), валюту и перечислите ID входящих медитаций. Один продукт может включать несколько практик. Опубликуйте и медитации, и продукт.
4. Для группы создайте продукт COMMUNITY: 30/90 дней либо пустой срок для бессрочного доступа. При смене тарифа срок добавляется к самому позднему действующему сроку сообщества. Опубликованные бессрочные доступы сохраняются при последующих покупках.
5. Для платной встречи сначала создайте продукт EVENT, затем событие со ссылкой на его ID. Для бесплатной встречи оставьте ID продукта пустым. Время формы — UTC; 18:00 Москвы = 15:00 UTC. Часовой пояс показа задаётся отдельно.
6. Скрыть запись можно снятием публикации. Физическое удаление контента и продуктов через UI не включено, чтобы сохранять историю продаж. Не меняйте состав уже проданного пакета без понимания последствий: доступ у покупателей относится к продукту и его текущему составу.

## Проверка оплаты

«Платежи → Квитанция» скачивает файл через сервер, не раскрывая токен бота. Сопоставьте **фактическое поступление в банковской выписке**, сумму и номер заказа. Только после этого нажмите «Подтвердить». То же действие доступно в уведомлении бота. При отклонении укажите причину в админке; пользователь сможет загрузить исправленную квитанцию. Кнопка отклонения в Telegram использует стандартную причину.

Повторное подтверждение не создаёт второй доступ. Совпадающий Telegram file_unique_id отклоняется; перефотографированная/изменённая квитанция может иметь другой ID, поэтому окончательное решение всегда по банковской выписке. Сверка банковских транзакций не автоматизирована.

При нехватке мест платёж не подтверждается. Проведите возврат вручную либо увеличьте лимит и повторите подтверждение. Места платных встреч не резервируются до проверки оплаты — об этом сообщает бот. Участников списка ожидания переводит владелец через «Участники встреч».

«Отметить возврат» доступно владельцу **после реального возврата в банке**. Это только запись операции; банковского перевода система не делает. Доступ к продукту отзывается целиком, включая продления этого продукта. При частичных возвратах требуется согласованное ручное решение — не используйте кнопку для частичного перерасчёта срока.

## Сообщество

Пользователь получает часовую ссылку на заявку вступления. Telegram не допускает одновременно creates_join_request и member_limit, поэтому персональность обеспечивается проверкой Telegram ID и одобрением ровно одной заявки. Ссылка отзывается после успешного входа. Чужие заявки отклоняются. Если ссылка истекла: «Мой доступ → Получить приглашение». При окончании всех доступов в сообщество cron исключит участника и снимет бан, чтобы позже он смог продлить подписку.

## Рассылки и настройки

Согласие запрашивается через `/subscribe`; по умолчанию маркетинг выключен. В настройках меняются приветствие, описание, политика, видео и меню. Для меню используется JSON-массив с label/action/hidden; порядок массива задаёт порядок кнопок. Реквизиты и токены меняются только в защищённых переменных сервера.

«Рассылки»: выберите сегмент и UTC-время, сохраните статус scheduled. Подписка на маркетинг и условия сегмента проверяются повторно перед отправкой. queued означает «получатели поставлены в очередь», а не «все доставлено»; результат смотрите в событиях пользователей и очереди. Отмена останавливает ещё не отправленные сообщения.

«Автоматизации»: включите и отредактируйте шаблоны до набора подписчиков. Шаги ставятся в очередь при явном согласии пользователя, задержка считается от этого момента. Укажите ID продаваемого продукта для подавления сообщения после его покупки. Изменение текста влияет на ожидающие отправки; изменение задержки не переносит уже созданные задания. Сложный конструктор воронок не входит в текущую реализацию.

Заявки на консультацию поступают в Telegram владельцу и в раздел «Консультации». Не просите присылать медицинские подробности. Экспорт пользователей и заказов в CSV доступен владельцу; файл содержит персональные данные, храните его с соответствующими ограничениями.
